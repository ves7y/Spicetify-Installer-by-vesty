# 🟠 Spicetify Installer

A simple, modern and fully automated installer for **Spicetify** and **Spicetify Marketplace**.

No complicated setup. Just launch the installer, click **Install Spicetify**, and let it do the rest.

## ✨ Features

* 🟠 Automatic Spicetify installation
* 🛒 Automatic Spicetify Marketplace installation
* ⚡ Fully automated setup
* 🎨 Modern dark interface
* 📊 Installation progress indicator
* 💬 Built-in Discord link
* 📦 Standalone Windows executable
* 🔧 No manual PowerShell commands required

## 🖥️ Requirements

* Windows 10 or Windows 11
* 64-bit system
* Spotify installed
* Active internet connection

You **do not need to install .NET** separately when using the published standalone installer.

## 📥 Installation

1. Go to the **Releases** section.
2. Download the latest `SpicetifyInstaller.zip`.
3. Extract the ZIP file.
4. Run `SpicetifyInstaller.exe`.
5. Click **Install Spicetify**.
6. Wait until the installation is completed.

That's it. 🎉

## 🛒 Spicetify Marketplace

The installer automatically installs **Spicetify Marketplace** alongside Spicetify.

After installation, Marketplace can be used to install themes, extensions and other customizations for Spotify.

## 🧡 Interface

The installer uses a custom dark interface with an orange accent, animated transitions and installation status information.
